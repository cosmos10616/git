## 对话与已核实结论

### 1. RX RRH与第一次跨板交换

- `RX_RRH_FIFO_Exchange`把4条RRH频域数据流按固定小块写入缓存，再串行为一条64-bit输出流，并给每个RB标记目标MIMO FPGA。
- 4路变1路不会持续堵塞：输入与输出按OFDM符号的突发/空隙调度工作，串行读取窗口小于相邻符号可用时间；FIFO负责吸收瞬时速率差。
- 相邻符号处理起点的17530/17660拍来自系统OFDM符号长度和长/短CP差异，不是RB数量。
- 工程4096点FFT对应61.44 MHz基带采样率时，4096点有效符号约66.67 μs；代码的符号调度还包含CP和内部启动偏移，应以RTL计数器为准。

### 2. RX MIMO数据主线

```text
两路64-bit天线FIFO
→ Read_and_Unpack恢复A0～A31自然顺序
→ Resource_Demapper标记导频/PSS/业务资源
→ Channel_Estimation_WDP4形成H(32×12)
→ Channel_Estimation_Extend缓存并在后续数据符号重放H
→ Weight_Matrix_Computation得到W(12×32)
→ Channel_Equalizer_WDP4计算x_hat=W y
→ RX_MIMO_Data_Processing把128-bit拆成64-bit
→ 跨板分回每片3条Layer
```

- 接收MIMO一次并行处理4个频域位置。一个RB有12个子载波，因此分成3个四位置小块。
- `Resource_Demapper`的OFDM处理发生在FFT后的频域；它主要给数据贴上RB、符号和资源类型标签。
- `Channel_Estimation_WDP4`利用本地已知导频和接收导频的复数相关/共轭乘法得到信道估计，输出144 bit，即4个`18+18 bit`复数。
- `Channel_Estimation_Extend`不是把矩阵从小尺寸补成`32×12`，而是把导频时刻已经得到的固定`H(32×12)`写入RAM，在后续没有导频的数据符号按RB和天线顺序重放。

### 3. MMSE权矩阵计算

- `Weight_Matrix_Computation`输入`H(32×12)`和`sigma`，输出`W(12×32)`；每拍输出12个复权值，共600 bit，连续32拍对应32根接收天线列。
- 工程没有直接实现矩阵求逆，而是构造增广矩阵：

```text
A = [H; sigma I]，尺寸44×12
A = QR
Q1 = Q的前32行
Q2 = Q的后12行
W = Q2 Q1^H / sigma
```

- 该实现等价于`W=(H^H H+sigma^2 I)^-1 H^H`。
- `Identity_Matrix_Attachment`把12列分成3个四列组，每组前32拍输出H，后12拍现场生成对应的`sigma I`行，因此输入96拍扩展成输出132拍。
- `submatrix_index=0/1/2`时，分别从增广矩阵第32、36、40行开始把sigma通过4级寄存器移动到四个复数位置，形成对角线。
- `DIV_U2_U15`不负责补单位阵，只计算`1/sigma`。它在`OFDM_symbol_start`时接收常数1和sigma，约27拍后用`div_valid`指示结果有效，结果供最后的`Q2 Q1^H / sigma`缩放使用。sigma必须保证非零。
- QR内部核心是Gram-Schmidt式的“列投影消除+向量归一化”；最后一级收集Q2，并与Q1做共轭点积。

### 4. Channel_Equalizer_WDP4与MIMO输出整理

- `Channel_Equalizer_WDP4`使用的`channel_estimation[599:0]`端口名容易误导，顶层实际接入的是`channel_inverse_column`，即MMSE权矩阵W，不是原始H。
- 对每一层、每个频域位置执行：

```text
x_hat(layer,k) = sum(a=0..31) W(layer,a) × y(a,k)
```

- 4套`Channel_Equalizer_Dot_Product_Group`并行处理4个频域位置；每组内部12个点积通路并行形成12层结果。
- `RX_MIMO_Data_Processing`不做均衡，只用FIFO把每拍128 bit（4个复数）、连续12拍，转换为每拍64 bit（2个复数）、连续24拍，总数据量不变。

### 5. RX BIT整体链路及与TX的关系

- `RX_BIT_Processor_Top`先通过节流器读取MIMO→BIT FIFO；`RX_Reordering`把RB优先顺序改成每条Layer连续4096点，并把64 bit转换成32 bit；`Triple_Strobe_to_Single`按三个连续4096点窗口分给本片3套`RX_BIT_Processor`。
- 每条Layer内部主线：

```text
补回直流位置
→ WFRFT_RX
→ 4096点中提取3600个有效子载波
→ PDCCH/PDSCH资源解映射
→ PDCCH恢复调制方式和TBS
→ PDSCH软解调得到LLR
→ 解扰
→ 速率解匹配
→ Turbo译码
→ TB/CB CRC
→ bit打包为UDP字节
```

- TX BIT与RX BIT在功能上成对，但RTL不是简单倒放：CRC是“添加/校验”，调制是“理想映射/带噪软解调”，速率匹配是“打孔重复/中性LLR补位和重复软信息处理”，Turbo是“编码/迭代译码”。
- Gold加扰和解扰使用相同序列；硬bit域是再次XOR，软bit域通常表现为按`c(i)`翻转LLR符号。

### 6. 明日关键模块复现计划

- 第一优先级：`Pilot_Generation_WDP4 → Channel_Estimation_WDP4 → Channel_Estimation_Extend`。
- 信道估计第一组复数测试建议使用`h={1,j,-1,-j}`，用于同时检查四通路顺序、I/Q、负数和定点缩放。
- MMSE第一组完整矩阵使用`H=[I12;0]`，不要用秩1的全1矩阵。其参考权重为`W=1/(1+sigma^2)[I12,0]`。
- 均衡闭环用软件构造`y=Hx`，比较RTL的`x_hat=W y`。
- Turbo先测试固定输入向量的编码结果和尾bit，再加入速率匹配；接收闭环先绕过QAM，按工程LLR正负约定构造强软信息，最后再加入加扰、QAM、噪声、软解调和CRC。
