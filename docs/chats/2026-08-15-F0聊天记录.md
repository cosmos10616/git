## 已核实的技术结论

### RAM_control

- `RAM_control`本身不计算频偏；它持续保存同步参考天线的历史时域IQ，在检测到PSS后回读精频偏估计需要的数据。
- 输入 `real/imag/valid` 同步延迟85个基带时钟，以对齐粗PSS检测链路。85拍是时钟延迟，不等于85个有效采样。
- RAM深度为 `2×FFT_LENGTH+CP_LENGTH1=2×4096+320=8512`，每个地址保存 `{imag[15:0],real[15:0]}` 一个32-bit复数采样。
- `Mod_N_Indexer`只在延迟后的 `data_in_valid=1` 时从0～8511循环递增，因此RAM地址的单位是有效复数采样点，而不是每个基带时钟。
- PSS触发时锁存 `basic_index`，通过 `sync_latch`置位 `disable_store_data`，暂停RAM写入以防历史数据被覆盖；触发再延迟1拍启动读地址发生器，保证后级使用已经锁存的 `basic_index`。
- 冻结的是RAM写使能，不是 `mod_index`。读取期间时间地址仍随有效输入继续前进，恢复写入后地址仍对应真实连续接收时间；精频偏读取始终使用触发时锁存的 `basic_index`。

### Read_RAM_for_PCFO

- `PULSE_TO_STROBE_U16`把单拍触发扩展成240拍 `working`，同时产生 `add_index=0～239`。
- `add_index[0]`区分一对数据的前后样本，`add_index[14:1]`形成对号 `n=0～119`：

  ```text
  add_index=2n   ：addr = basic_index + n + 151
  add_index=2n+1 ：addr = basic_index + n + 4247
  ```

- 两地址偏移始终相差 `4247-151=4096`，因此输出顺序为 `early0,late0,early1,late1,...,early119,late119`，共240个复数采样、120对。
- 常数来自环形地址中的负偏移表示：

  ```text
  151  = (31 - 8192 - 200) mod 8512
  4247 = (31 - 4096 - 200) mod 8512
  ```

  其中4096点间隔是算法核心；31用于补偿粗PSS索引关系，200将取数点提前到CP内部。
- 两段数据对应CP内部和有效OFDM符号尾部的复制内容。无频偏时两段近似相同；存在频偏时，两段相隔4096个采样后形成固定相位旋转，后级通过120对共轭复乘、累加和求相位估计频偏。
- 未取模地址最多只跨过一个8512深度，父模块执行一次 `r_addr-MAX_ADDR` 即可得到实际环形地址。
- RTL将读地址有效信号延迟3拍形成 `data_out_valid`，并将最后地址标志同样延迟3拍形成 `finish`；设计意图是等最后一个RAM读数输出后再恢复写入。
- 当前RTL实际输入后级的是240拍并完成120对运算；源文件中“120拍”“60次乘法”以及旧2048点参数相关注释属于历史残留。
